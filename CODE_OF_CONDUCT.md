# Code of conduct

Oyster is a small project and wants to stay a pleasant place to contribute.

- Be respectful and assume good faith. Disagree about code, not about people.
- No harassment, insults, or discriminatory language, in any project space: issues, pull
  requests, discussions, or anywhere you represent the project.
- Help newcomers. Bluetooth on Linux is confusing; nobody is expected to know it already.

The maintainer may edit or remove comments, close threads, or block people who do not follow these
rules. To report a problem privately, use the contact described in `SECURITY.md`.
